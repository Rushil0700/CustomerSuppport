# Prepare evidence for a security audit

## Who this is for

Workspace owners and admins. Some steps need the owner role, which is noted
where it applies.

## Steps

1. Export the audit log for the period under Settings > Security > Audit log.
2. Request the SOC 2 Type II report and ISO 27001 certificate from support - both are available under NDA.
3. Download the DPA with standard contractual clauses from Settings > Legal.
4. Screenshot the security configuration: MFA enforcement, session policy, IP allowlist, SSO.
5. Where the auditor needs continuous evidence, Enterprise workspaces can stream audit events to a SIEM.

## Verify

The auditor has the log export, the certifications, the DPA and the configuration evidence.

## When to escalate

Escalate when a step cannot be completed because the required control is absent
from your plan, or when the verification above does not hold after completing
every step.
