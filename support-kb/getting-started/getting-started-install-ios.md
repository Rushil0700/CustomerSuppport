# Install Acme Cloud on the iOS app

## Steps

1. Download the current build from acme.example/download.
2. Run the installer and sign in with your workspace address.
3. Choose a local folder; the default is fine unless you keep data on a second drive.
4. Pick which projects sync to this device - start with one to confirm it works.

## Platform note

Force-quit by swiping up from the app switcher before retrying.

## Verify

The tray or menu bar icon shows a green check and files appear in the chosen folder.
