# Organise work into projects on the iOS app

## Steps

1. Create one project per team, client or initiative rather than per file type.
2. Set access at the project level; files inherit it.
3. Archive projects when they finish - archived projects stay searchable and cost half the storage.
4. Use a shallow folder structure inside projects; search is faster than nesting.

## Platform note

Force-quit by swiping up from the app switcher before retrying.

## Verify

The project list reflects how your team actually talks about its work.
