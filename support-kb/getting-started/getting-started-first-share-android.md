# Share your first file on the Android app

## Steps

1. Select a file and choose **Share**.
2. Share with a person by email, or create a link.
3. Set an expiry and, for anything sensitive, a password.
4. Choose view or edit access - view is the safe default.

## Platform note

Use Settings > Apps > Acme Cloud > Storage > Clear cache (not Clear data).

## Verify

The recipient opens the file and the share appears in Activity.
